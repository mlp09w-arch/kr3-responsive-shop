# Lighthouse Accessibility

Отчёты обновлены 11.11.2026 после проверки проекта. Инструмент — Lighthouse 13.6.0, Chromium 151, категория Accessibility, мобильный режим. Все пять страниц получили 100/100; даты и показатели перечислены в `results.json`.

## Как открыть

- На Pages: https://mlp09w-arch.github.io/kr3-responsive-shop/lighthouse/index.report.html
- Локально: скачайте `.report.html` и откройте двойным щелчком в браузере.
- Через локальный сервер: запустите `python3 -m http.server 8000` в корне проекта и откройте http://localhost:8000/lighthouse/index.report.html.

GitHub на странице файла показывает его код. HTML-отчёт содержит собственный скрипт Lighthouse для отрисовки результатов, поэтому JavaScript для просмотра отчёта должен быть разрешён. Страницы магазина скриптов не используют.

Адрес `127.0.0.1:8010/kr3-responsive-shop/` внутри отчётов относится к локальному тестовому серверу. Отчёт не нужно запускать по этому адресу на другом компьютере.

## Как повторить

Откройте страницу → DevTools → Lighthouse → Accessibility → Mobile → Analyze page load. Затем сохраните HTML-отчёт. На главной, каталоге и заявке проверка обязательна по методичке; дополнительно проверены товар и контакты.

Lighthouse не заменяет проверку клавиатуры, фокуса, поведения формы и промежуточных ширин. Эти сценарии проверены отдельно; их результаты находятся в `docs/verification.json`. 100 баллов Accessibility не означают, что Performance, безопасность и соответствие всем требованиям WCAG тоже полностью проверены.
