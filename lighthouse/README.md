# Lighthouse Accessibility

Полные отчёты Lighthouse 13.6.0 для пяти страниц «СветДом», полученные 08.11.2026 в Chromium 151 на локальном HTTP-сервере. Форм-фактор — mobile; проверялась категория Accessibility. Результат каждой страницы — 100/100, проваленных автоматических проверок нет.

HTML-отчёт можно скачать и открыть в браузере либо запустить сайт через `python3 -m http.server 8000` и открыть, например, http://localhost:8000/lighthouse/index.report.html. В GitHub обычный просмотр `.html` показывает исходный код отчёта.

Адреса `127.0.0.1:8000` внутри отчётов относятся к локальной проверке исходных файлов, не к опубликованному сайту. Результаты перечислены также в `results.json` с временем каждого запуска и версией инструмента.

Для повторения: откройте нужную страницу → DevTools → Lighthouse → Accessibility → Mobile → Analyze page load. Сохраните HTML-отчёт. Для проверки именно разметки отключение JavaScript на сайте допустимо: внешних и собственных скриптов здесь нет.

Автоматический аудит дополнен проверкой ширин 360/430/768/1024/1440 px, клавиатуры, нативного меню и диалога, фокуса и учебных форм. 100 баллов Accessibility не являются гарантией полного соответствия WCAG и не заменяют ручную проверку.
